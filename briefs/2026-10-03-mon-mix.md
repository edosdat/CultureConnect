## Quoi faire

Une page **`/mix`** autonome, et **un petit bouton « Mon mix »** sur l'accueil qui y mène. Rien d'autre ne change.

### 1. Le bouton d'entrée
- Sur l'accueil, à droite du champ de recherche (`#cc-search` ou son conteneur), un bouton **« Mon mix »** avec une icône de curseurs.
- Style **secondaire** : contour crème 1,5 px à 55 %, texte crème, icône rose, hauteur 48 px, coins ronds. **Jamais un bouton rose plein** : ce n'est pas l'action principale.
- Il mène à `/mix`. Visible pour tous (invité ou connecté).
- Si la largeur manque (moins de 360 px), afficher l'icône seule avec `aria-label="Mon mix"`.

### 2. La page `/mix` (mobile d'abord, 390 px de large)
Reprendre la maquette `M1_Mix-maquette.dc.html`, **aux couleurs du thème nuit** (tokens `planc-*` / `culture-*` déjà en place), comme sur `mix-reference.png`.

De haut en bas :
1. **En-tête** : bouton retour (44 px) vers `/` ; titre « Ton *mix* de ce soir » (Fraunces 800, le mot *mix* en italique rose) ; sous-titre « Pousse ce qui te tente, baisse le reste. »
2. **Mix tout prêts** (rangée qui défile horizontalement), un tap applique les valeurs :

   | Mix | Rire | Frisson | Émotion | Fête | Cérébral |
   |---|---|---|---|---|---|
   | Ton mix | profil (voir §4) | | | | |
   | Soirée fou rire | 95 | 5 | 20 | 60 | 10 |
   | Un truc qui secoue | 5 | 95 | 40 | 20 | 60 |
   | Tout doux | 20 | 0 | 95 | 0 | 40 |
   | Ça va danser | 40 | 10 | 10 | 100 | 0 |
   | Surprends-moi | 100 − profil, curseur par curseur | | | | |

   Le mix actif : fond crème, texte nuit. Toucher un curseur désélectionne le mix.
3. **Les 5 curseurs verticaux**, dans une carte velours :
   - curseurs Rire (pêche #FF9E6D), Frisson (cerise #FF4D6D), Émotion (menthe #5EEAD4), Fête (citron #FFD23F), Cérébral (aubergine #B98CFF) ;
   - valeur de 0 à 100 affichée au-dessus, dans la couleur du curseur ;
   - un **trait gris** marque la valeur du profil (« ton type ») ;
   - curseur maison : `role="slider"`, `aria-valuenow`, flèches du clavier ±10, glisser au doigt (pointer events, `touch-action: none`) ;
   - zone tactile ≥ 44 px de large, pas de 5.
4. **Crossfader** « Mon type ↔ Ce soir » : `<input type="range">` de 0 à 100, pas de 5, 70 par défaut. Sous lui, la phrase : « 70 % ce soir, 30 % ton type » ; aux extrêmes, « Rien que ton type » / « Rien que ton envie de ce soir ».
5. **Résultats** :
   - titre « {n} plans » et filtres Tout / Vivant / Musique / Ciné (sélection en crème) ;
   - liste des **10 premiers** : vignette (affiche du catalogue, ou dégradé de la couleur dominante si absente), titre, « catégorie · jour heure · lieu », pastille de couleur du curseur qui a le plus compté, et le score en %.
   - Un tap ouvre la fiche existante : `/?e=<itemKey>` (même lien que le partage, `deepLinkUrl`).

### 3. Le calcul (fonctions pures, testées)
Nouveau fichier `src/lib/mixFaders.ts`.
- **Données** : les plans de la **semaine** via l'API existante (`/api/agenda?scope=semaine`), côté client, une fois au chargement.
- **Vecteur d'un plan**, 5 valeurs de 0 à 1, à partir de ses `moods` (v1 aujourd'hui) :
  - correspondance : Rire = rigolo, absurde, leger ; Frisson = intense, angoissant, sombre, brutal, epique ; Émotion = tendre, poetique, intimiste, contemplatif ; Fête = festif, dansant ; Cérébral = cerveau, critique. `sortie` est ignoré ;
  - poids d'un mood = rang (1er 1, 2e 0,6, 3e 0,3) × confiance (`mood_confiance` : haute 1, moyenne 0,8, basse 0,5, absente 0,8) ;
  - valeur d'un curseur = le **max** des poids de ses moods.
- **Plans sans mood** : exclus du classement (ne pas inventer).
- **Cible** = profil × (1 − dosage) + curseurs × dosage, avec dosage = crossfader / 100.
- **Score** = cosinus entre la cible et le vecteur du plan ; on trie par score décroissant, puis les 10 premiers. La pastille = le curseur où (cible × plan) est le plus grand.
- **Catégories** : Ciné = `cinema` ; Musique = `musique` ; Vivant = le reste (théâtre, danse, enfants, festival…).
- **Peu de résultats** (moins de 3 plans avec un score > 0,3) : afficher « Peu de plans pour ce mix cette semaine. Essaie un autre réglage. » plutôt qu'une liste faible.

### 4. Le profil (« Ton mix » et le trait gris)
- **Connecté** avec des goûts connus : convertir ses poids de moods (`AccountTasteState`, mêmes moods que ci-dessus) avec la même correspondance, puis ramener le plus fort à 0,8 et les autres en proportion.
- **Invité, ou sans goûts** : profil neutre `[0,5 ; 0,2 ; 0,5 ; 0,5 ; 0,3]`.
- **Lecture seule** : régler le mix ne modifie **pas** le profil ni les signaux de reco.

6. Un tap sur un plan ouvre sa fiche.
