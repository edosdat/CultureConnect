## Cause (vérifiée sur le catalogue du tip)

`itemInheritsParentClosedTags` refusait tout tag parent dès qu’une ligne était un film (`film_id` ou slot ciné). Les moods du parent ne rentraient donc pas dans le score.

Stock `leger` visible au scoring, jours problématiques :

| Jour | Avant (P0) | Après |
| --- | --- | --- |
| Lundi 2026-09-21 | 0 ligne. 13 séances E003 (Utopia Borderouge) ont le parent `rigolo\|cerveau\|epique\|tendre\|festif\|critique\|leger\|intense`, et `leger` n’est sur aucune séance. 0 théâtre, 0 concert. | 13 séances ciné E003 héritent `leger` (et les 7 autres moods fermés du parent). Théâtre et concert toujours à 0. |
| Vendredi 2026-09-25 | 0 ligne, toutes formes. | 0 ligne. E003 et E006 s’arrêtent le 2026-09-23. Aucun parent du vendredi ne porte `leger`. L’héritage ne peut pas en créer. |

E006 porte aussi `leger` (11 moods) mais n’a pas de séance le lundi. La référence `moodStockReference` reste « ciné 0 » : elle compte les tags collés sur les lignes, pas les moods lus sur le parent au scoring.

## Correctif

Les lignes film héritent des **moods** du parent pour le matching, filtrés par la bibliothèque fermée. Genres et thèmes du parent ne passent pas (union des œuvres sœurs). Le magasin `films.csv` / séances sœurs ne copie toujours pas la saison. `demoteWorkIds` reste hors de `agendaQuery` (0 T5).

Why-lines UI (`reasonTasteSlugsForItem` / `displayReasonForItem`) : toujours les tags de la séance seule. Une carte Top 3 peut donc matcher `leger` sans afficher « parce que tu aimes le léger ». Smoke UI non fait.
